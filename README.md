# LATICS — site

Site institucional do LATICS (Laboratório de Tecnologias de Informação e Comunicação em Saúde, UFCG/UFFS),
com painel administrativo. Feito em Vue 3 + Firebase; o código fica em [`web/`](web/README.md).

No ar em https://repositorio-latics.web.app.

A versão anterior, em Django, foi removida em outubro de 2026 e continua no histórico do git (até o commit `cc2e0e0`).
Os projetos dela foram importados como tecnologias; o link antigo `/projeto/<id>` redireciona para `/tecnologias/<id>`.
